# 收盘见 CloseCall · 项目说明

**第一段：思路。** 交易社区里，预测可以不断改口，截图可以只保留猜对的部分，流畅的AI分析也容易让主观概率显得可靠。收盘见把“我认为会涨”变成一条有期限、可复核的二元判断。核心假设：先固定问题、基准、截止和核验来源，让AI独立作答，再封存人类概率与理由，最后用真实数据核验和Brier计分，能帮助用户发现自己与模型的过度自信。流程是“真实数据→独立判断→封存→等待→程序核验→原判断收据”。价格裁定由明确程序执行，模型不能凭叙述投票决定涨跌；数据冲突或过期则等待或不计分。产品不连接交易账户，也不接受资金押注。

**第二段：目标用户与产品价值。** 首批目标是使用美股相关产品的Retail用户：风险偏好中等、持仓规模约1,000–50,000美元等值、每周关注1–5次事件或市场方向、经常在社交平台表达短期观点。这是产品假设，尚未通过真实用户招募验证。具体场景是：开盘前认为NVDA会涨，却无法记清当时到底有多确定、用了什么资料；收盘后再回看，容易受到结果影响。用户可以与同一题上的DeepSeek比较原始概率、理由和证据，用连续收据而不是选择性截图复盘。首版支持NVDA、AAPL、MSFT、TSLA、AMZN、META；原生股票USD收盘和Bitget股票永续USDT短时加赛分开，防止错把两种价格当成同一资产。

**第三段：验证数据与关键指标。** 已完成真实前瞻开发验证，而非历史回测：一场NVDAUSDT加赛基准234.76 USDT，约定窗口内取得终值234.69 USDT，结果为NO。DeepSeek给出的P(YES)=42%，本场Brier=0.1764；开发者固定50%基线为0.25。另有一场云端NVDAUSDT自动核验：234.76→234.94 USDT，YES；AI 42%预测Brier=0.3364，开发者50%为0.25，人工基线更低。两场分别保留，不挑选有利结果。首场模型调用2.895秒、总5818 tokens；这些均为单场实测，不代表稳定预测优势、实盘收益或真实用户认可。六个支持标的的Bitget官方SDK股票永续报价与原生股票背景数据均在本机实测取得；官方美股MCP失败项明确保留。另有一场AAPL原生收盘挑战已封存，目标纽约2026-10-05收盘，目前尚未到期。41项软件测试用于核对规则、时间、引用关联、权限与异常；不计为用户样本。真实外部测试用户目前0人，任务完成率、留存和独立校准优劣尚无数据。后续计划招募至少3位目标用户完成统一任务，记录独立提交完成率、时间、市场/概率误解及再次使用意愿；持续积累前瞻预测，与固定50%和动量基线同题比较，报告样本量和区间。初期目标为任务完成率≥80%、3分钟内完成提交，均为目标值；无Trading Volume、AUM或收益声称。

**第四段：完成度。** 已实现六标的、两种市场、官方只读取数、DeepSeek独立预测、隐藏答案、服务端截止检查、不可覆盖原回答、签名访客隔离、主动公开分享、自动到期核验、按市场分榜、真实证据与失败记录、Markdown/JSON导出。技术为Next.js、TypeScript、Node.js 24 SQLite与服务端DeepSeek兼容API。Bitget具体使用官方@bitget-ai/bitget-agent-sdk的discover、market.instruments/tickers/orderbook/candles，以及美股MCP的initialize、guide、do_query equity_price_quote。原生美股来自Yahoo Finance日线，Nasdaq精确历史收盘作备用基准和结算交叉核验；限流时启用备用源，但不以同一来源伪装双源核验。实时Demo不使用模拟行情；测试夹具与实际记录分开。仍未完成大样本校准、真实用户研究、第三方时间锚和账户级身份认证；哈希封存不是链上不可篡改证明，不能防数据库管理员重写。下一步扩大前瞻样本、增加第三方时间锚与事件类问题。

**第五段：对AI Trading的看法。** AI除了产生观点，还应承担可复核的承诺：作答时明确概率、证据和边界，到期保留原答案，允许事实证明自己错了。Bitget官方只读SDK的工具发现与身份字段，让“用了哪个工具、查了哪类资产”能进入证据链；美股MCP可用性与时间粒度仍需要更一致的说明。建议统一提供as-of时间、延迟、交易时段、原生/衍生品身份与修订标记。CloseCall先验证“判断有没有接受检验”，再考虑更长的执行闭环；原型阶段不把预测分数包装成收益，也不让模型同时充当裁判和成绩证明人。
